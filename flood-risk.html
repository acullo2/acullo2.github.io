Coastal Flood Risk Assessment

Multi-criteria flood vulnerability model for three coastal counties
QGIS Python Raster Analysis DEM

Overview

This project developed a multi-criteria flood vulnerability model for three coastal counties. Integrated DEM, precipitation data, land cover, and proximity to water bodies. Used Analytic Hierarchy Process for weighting.

Methods

Built Python scripts in GeoPandas and Rasterio to automate data preprocessing. Reduced analysis time from two weeks to three days.

Results

Delivered maps as static layouts and interactive Leaflet maps for emergency management.
